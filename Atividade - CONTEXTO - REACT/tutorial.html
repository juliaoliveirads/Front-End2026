Construindo o Contexto com React

Um guia completo e aprofundado para engenharia de estados imutáveis, renderização de layouts condicionais e cálculo de distribuições proporcionais contínuas.

Neste tutorial exaustivo, vamos decompor cada linha de código necessária para recriar o motor de regras e a interface reativa do jogo Contexto. Abordaremos tópicos essenciais de ciclo de vida do React, manipulação de vetores na memória interna do cliente e como as propriedades computadas definem a largura e o preenchimento exato dos elementos gráficos em tela.

Arquitetura do Mecanismo

Para construir esta aplicação, o React opera sobre o conceito de Programação Declarativa. Em vez de dizermos ao navegador como mudar os elementos visuais passo a passo usando seletores como document.getElementById(), criamos variáveis internas chamadas Estados. Quando o valor de um Estado muda, o React redesenha automaticamente a tela de forma otimizada usando seu DOM Virtual.

Pré-requisitos Conceituais

Para o aproveitamento total deste documento, é importante compreender o uso de funções de alta ordem de JavaScript, especificamente o método .map() para transformações de listas e o operador de espalhamento (Spread Operator ...) para cópia de estruturas em profundidade.

A Regra da Mutabilidade Direta

Em hipótese alguma altere o estado do React fazendo atribuições diretas, como historico = [] ou ganhou = true. O React monitora as alterações de dados exclusivamente através das funções despachantes criadas pelo Hook (ex: setHistorico, setGanhou).

3O Algoritmo Fuzzy de Hash para Palavras Extras

Para evitar que o jogo rejeite termos que não estejam pré-cadastrados em nossa constante global, criamos um mecanismo matemático determinístico. Esse método lê os códigos de caracteres individuais da string e gera um número estável, garantindo que a aplicação nunca pare de responder.

const gerarRankFuzzy = (palavra) => {
    const termo = palavra.toLowerCase().trim();
    
    // Se for o alvo, o rank absoluto é o topo
    if (termo === PALAVRA_SECRETA) return 1;
    
    // Se a palavra constar no dicionário estático, retorna seu valor real
    if (DICIONARIO_COMPLETO[termo]) return DICIONARIO_COMPLETO[termo];

    // Algoritmo clássico de espalhamento numérico para palavras não catalogadas
    let hash = 0;
    for (let i = 0; i < termo.length; i++) {
        hash = termo.charCodeAt(i) + ((hash << 5) - hash);
    }
    
    // Normaliza para situar os termos extras em um quadrante distante do topo
    return Math.abs(hash % 40000) + 5000;
};

4Despachando Palpites e Garantindo a Imutabilidade

A função enviarPalpite manipula os dados recebidos pelo formulário. Quando o formulário é enviado, processamos a palavra, geramos sua posição e a inserimos na lista histórica preservando a imutabilidade por meio do empacotamento funcional.

const enviarPalpite = (e) => {
    // Interrompe o envio padrão do formulário que causaria o reload da página inteira
    e.preventDefault();
    setMensagemStatus('');
    
    if (!palpite.trim() || ganhou) return;

    const termo = palpite.toLowerCase().trim();

    // Validador de redundância: verifica se o objeto já existe no histórico atual
    if (historico.some(item => item.palavra === termo)) {
        setMensagemStatus('A palavra já foi.');
        setPalpite('');
        return;
    }

    const posicao = gerarRankFuzzy(termo);
    const novaTentativa = { palavra: termo, posicao, foiDica: false };

    // Atualização Imutável com Ordenação Dinâmica:
    // Copiamos a lista anterior e aplicamos .sort() para ordenar as melhores palavras no topo
    setHistorico(prev => [novaTentativa, ...prev].sort((a, b) => a.posicao - b.posicao));
    
    // Limpa o conteúdo escrito no input de texto
    setPalpite('');
    
    // Retorna automaticamente o cursor para dentro da caixinha de digitação do usuário
    inputRef.current?.focus();

    if (posicao === 1) {
        setGanhou(true);
    }
};

5Lógica de Redução de Estado do Botão de Dica

A funcionalidade de dicas calcula o menor número de rank contido nas tentativas atuais e o divide de forma exata por 2. A partir desse valor-alvo intermediário, o algoritmo varre o dicionário em busca da palavra correspondente ideal.

const acionarDica = () => {
    setMenuAberto(false);
    setMensagemStatus('');
    if (historico.length === 0) return;

    // Acha o menor valor numérico presente dentro do array de objetos do histórico
    const melhorChute = Math.min(...historico.map(h => h.posicao));
    
    // Executa a operação matemática central de redução definida pela regra de negócio
    const alvoDica = Math.max(1, Math.floor(melhorChute / 2));

    let melhorPalavra = '';
    let menorDiferenca = Infinity;

    // Varre as chaves do dicionário estático para encontrar o termo não utilizado mais próximo
    Object.entries(DICIONARIO_COMPLETO).forEach(([palavra, posicao]) => {
        if (!historico.some(h => h.palavra === palavra)) {
            const diferenca = Math.abs(posicao - alvoDica);
            if (diferenca < menorDiferenca) {
                menorDiferenca = diferenca;
                melhorPalavra = palavra;
            }
        }
    });

    if (!melhorPalavra) {
        melhorPalavra = `alvo_${alvoDica}`;
        DICIONARIO_COMPLETO[melhorPalavra] = alvoDica;
    }

    const posicaoDica = DICIONARIO_COMPLETO[melhorPalavra];
    const novaTentativa = { palavra: melhorPalavra, posicao: posicaoDica, foiDica: true };

    // Insere a palavra da dica diretamente no fluxo do histórico reordenado
    setHistorico(prev => [novaTentativa, ...prev].sort((a, b) => a.posicao - b.posicao));
    
    // Escreve a explicação detalhada que será impressa dentro da modal de dica
    setMensagemDica(`Como o seu melhor chute foi #${melhorChute}, dividimos por 2 para buscar o alvo #${alvoDica}.\n\nPalavra encontrada: "${melhorPalavra}" na posição #${posicaoDica}.`);
    setModalDica(true);

    if (posicaoDica === 1) {
        setGanhou(true);
    }
};

6Cálculo Proporcional Logarítmico Contínuo

Para evitar distorções no preenchimento visual dos cards de palavras muito distantes, o preenchimento não utiliza valores fixos ou porcentagens lineares cruas. Implementamos um cálculo matemático baseado no logaritmo natural do valor máximo para suavizar a diferença entre as barras de progresso de forma contínua.

const calcularLarguraPreenchimento = (posicao) => {
    // A palavra secreta ocupa a totalidade da barra
    if (posicao === 1) return 100;
    
    const rankMaximoMaximo = 50000;
    
    // Math.log mitiga as diferenças gigantescas nas curvas de distribuição numérica
    const fatorProporcional = Math.log(rankMaximoMaximo) - Math.log(posicao);
    const baseLogaritmica = Math.log(rankMaximoMaximo);
    
    let porcentagem = (fatorProporcional / baseLogaritmica) * 100;
    
    // Aplica restrições de design para que os números de rank fiquem visíveis no fim dos cards
    if (posicao <= 300) {
        return Math.min(94, Math.max(82, porcentagem));
    } else {
        return Math.min(80, Math.max(4, porcentagem));
    }
};
